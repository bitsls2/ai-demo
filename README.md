# AI-Demo

The repository contains notes for a AI demo to highlight the possible use cases for OKF and webMCP for the public sector.

The idea is to make the demo less abstract by using examples relevant to the DWP. 

Note the demo is restricted to using information within the public domain.

## Demo 1 -  Build on OKF Bundle for DWP Decision Makers Guide: staff guide 

[staff guide](https://www.gov.uk/government/collections/decision-makers-guide-staff-guide)

### Demo 1 -Purpose

This purpose of the demo is to show that it is far more efficient to use AI agent friendly documentation. i.e. it reduces the number of tokens required and provides better context.  

## Demo 2-  Build a website for a DWP Benefit Application which includes support for webMCP  

### Demo 2 - Purpose 

This purpose of the demo is to show that it is far more efficient and flexible to create a website that supports AI agents. The avoids agents having to navigate HTML pages and include additional tooling.
